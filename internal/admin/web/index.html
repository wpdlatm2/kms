비밀번호를 변경하세요

2단계 인증(OTP) 설정

비밀번호에 더해 휴대폰의 인증 앱으로 만든 6자리 코드를 입력하게 됩니다. 아래 무료 앱 중 하나를 설치하세요 (Android·iOS 공통 표준 TOTP).

  • Google Authenticator — Android / iOS
  • Microsoft Authenticator — Android / iOS
  • 2FAS — Android / iOS (오픈소스)
  • Aegis(Android, 오픈소스) · FreeOTP(Android / iOS)

앱에서 QR 코드 스캔을 선택하세요. 스캔이 안 되면 앱의 “설정 키 입력”에 아래 키를 넣으세요 (시간 기반, 6자리, 30초).

설정이 완료되었습니다. 아래 복구 코드를 안전한 곳에 보관하세요. 휴대폰을 잃어버렸을 때 코드마다 한 번씩 OTP 대신 사용할 수 있고, 이 화면에서만 표시됩니다.
